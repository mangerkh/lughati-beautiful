لعبة ذاكرة الكلمات — مطابقة الكلمة بمعناها

الأزواج:
عطش = احتاج إلى الماء.
منقار = فم الطائر الصلب.
جرة = وعاء للماء.
ارتفع = صار أعلى.
ارتوى = شرب حتى زال عطشه.

المميزات:
- 10 بطاقات = 5 أزواج.
- تقليب بطاقتين في كل محاولة.
- بقاء الزوج الصحيح مفتوحاً.
- إغلاق الزوج الخاطئ تلقائياً.
- عداد محاولات.
- نقاط.
- أصوات نجاح وخطأ.
- نطق الكلمة/المعنى.
- Confetti عند إنهاء اللعبة.
- Responsive للجوال.
