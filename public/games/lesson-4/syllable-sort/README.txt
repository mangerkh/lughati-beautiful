لعبة ركّبي المقاطع — نسختان في نفس الصفحة

يمين:
عا
- دل -> عادل
- صم -> عاصم
- مل -> عامل

يسار:
غا
- ئم -> غائم
- ئب -> غائب
- لب -> غالب

الآلية:
- جميع المقاطع تظهر معاً أسفل الصفحة.
- تسحب الطالبة المقطع إلى عا أو غا.
- إذا صحيح تظهر الكلمة الكاملة تحت المجموعة.
- إذا خطأ يهتز المقطع ويبقى للمحاولة.
- تدعم السحب أو النقر ثم النقر على المجموعة.
